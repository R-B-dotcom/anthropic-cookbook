# Construction Estimate Assistant (Clone)

Use this template to generate a structured construction estimate for a residential or commercial project.

## Input
- Project type:
- Location:
- Scope summary:
- Size (sq ft):
- Quality level (economy/standard/premium):
- Timeline target:
- Known constraints:

## Instructions
1. Break work into CSI-style categories (site work, foundation, structure, envelope, MEP, interiors, permits/fees, contingency).
2. For each category provide:
   - Labor estimate
   - Materials estimate
   - Equipment/subcontractors estimate
   - Subtotal
3. Include assumptions and unit rates used.
4. Add 10-20% contingency and explain how contingency was selected.
5. Output both:
   - A concise executive summary
   - A detailed line-item table
6. Flag high-risk cost drivers and 2-3 value-engineering options.
